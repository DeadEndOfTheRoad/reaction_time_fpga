# VISUAL REACTION-TIME GAME

## Overview

This project implements a reaction-time tester in SystemVerilog on the RealDigital Boolean board. A finite state machine waits a random interval from ~2.7s to ~8.5s, switches an on-board LED from red to green, and measures - to the millisecond - how fast the player responds by pressing a button. The result is displayed live on the board's 7-segment display in milliseconds (a maximum of 8191 milliseconds, after which it will wrap around from 0ms if you take longer to press the button).

The random wait is generated by a free-running LFSR that gets frozen the instant the "waiting" state begins, so the delay length depends on the exact cycle the round was started on making each round unpredictable without any external seeding.
